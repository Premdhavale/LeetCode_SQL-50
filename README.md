# LeetCode SQL 50 Solutions

This repository contains my solutions to the **LeetCode SQL 50 Study Plan**, covering the most important SQL concepts used in coding interviews and real-world database queries.

## Topics Covered

* Basic SQL Queries (SELECT, WHERE, ORDER BY)
* Filtering & Conditional Statements
* INNER, LEFT & RIGHT JOINs
* GROUP BY & HAVING
* Aggregate Functions (COUNT, SUM, AVG, MIN, MAX)
* Sorting & Grouping
* Date Functions
* String Functions
* CASE Statements
* Subqueries
* Common Table Expressions (CTEs)
* Window Functions
* Self Joins
* Ranking & Advanced SQL Problems

## Difficulty

* 🟢 Easy
* 🟡 Medium
* 🔴 Hard

These solutions are written to improve SQL problem-solving skills, strengthen database fundamentals, and prepare for technical interviews at top companies.
